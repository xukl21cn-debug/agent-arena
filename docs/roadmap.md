# 当前状态与候选方向

## 正在验什么

开发交接已集中到工作域。看板、多轮返工、收工确认和合并放行已实现，**仍待独立评审与用户验收**。原生 Codex 与 DSH 试跑走通了返工、收工确认和看板放行，Git 写入受阻。另一次 SDK 与浏览器试跑在隔离仓库完成了合并验证。

## 下一次产品反馈

先从大厅进入开发任务看板，用一次确实需要跨客户端交接的重构验证三件事：用户能否看懂为什么退回，执行者能否直接收到意见，放行后能否查到合并提交和验证结果。先记录体验与阻塞，再由用户决定下一项。

## 尚未排期

- **接口与状态复核。** 复核聊天转录在 `limit: 0` 时的返回、非法棋类规则的错误码，以及按参与者身份调用 REST 时的在线状态刷新。
- **界面体验复核。** 触屏点名、聊天室暂停或关闭的提示、围棋观战时的数子操作、错误文案中文化和返回大厅。中文输入法的合成事件已验证，仍需用真实输入法体验。
- **聊天提示词。** 若仍观察到成员想让出轮次却没有调用 `pass_turn`，用真实客户端比较提示调整前后的实际调用。
- **runner 与更多聊天模式。** 若停车收件无法满足真实使用，再评估 runner 或会话续接。若轮流发言限制讨论，再评估 `mentions` 或 `free` 模式。[聊天模型](../server/src/chat/model.ts)
